# Product documentation

This directory contains normative, cross-functional product documents that
apply across the Ayla backend, AI backbone, bot, Mini App, and mobile clients.

## Structure

- `user-journeys/` — approved experience charters and implementation-level
  journey specifications.
- `foundations/` — reserved for the Ayla Constitution, Product Thesis, and
  other approved foundational documents once they are imported into Git.

Feature-specific PRDs that already live at the root of `docs/` remain there
until a dedicated documentation reorganization is approved.
