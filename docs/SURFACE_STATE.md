# Состояние поверхности

**Ещё не снято ни разу.** Этот файл — заглушка из PR DRF-1661: он существует,
чтобы у команды было куда писать, а у читателя — понятное место, где искать.
Числа появятся после первого прогона на пилоте:

```
docker compose exec backend python manage.py surface_state --write docs/SURFACE_STATE.md
```

Что окажется здесь после прогона (в этом порядке):

1. **Предмет** — кто отвечал на замер: hostname процесса, id контейнера,
   адрес БД по настройкам и по её собственному ответу, время старта
   процесса БД, пульс по нескольким опорам с возрастом каждой, время снятия.
   Молчание всех опор печатается как «свежесть НЕ подтверждена», не как ноль.
2. **Предел** — команда показывает данные, а не поведение.
3. **Числа** — тенанты, специалисты, рабочие часы, услуги, записи, питание,
   цели; у каждого числа рядом таблица и поле, из которых оно снято.

Пока здесь заглушка, любой «замер поверхности» в чате — это пересказ, а не
источник: снять командой и закоммитить вывод.
